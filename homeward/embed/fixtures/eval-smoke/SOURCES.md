# eval-smoke fixture — source and license

## Purpose

These images validate the **harness arithmetic**, not real-world re-ID accuracy.
They are solid-color synthetic PNGs generated by `generate_fixture.py`.

## What this proves

1. **Harness arithmetic**: Rank-1 for a near-identical query image ≥ Rank-1 for a
   clearly-different individual.  If the embedder maps similar images to nearby
   vectors, dog1's query will retrieve dog1's gallery entry at Rank-1.
2. **Disjoint guard**: gallery individuals (dog1, cat1, dog2) and query individuals
   (dog1, cat1, dog2) share IDs — this is expected because the same individual
   contributes both gallery and query images.  The anti-tautology guard checks that
   no query individual appears in the gallery *from a different split*, which is
   satisfied here.

## What this does NOT prove

- Real-world re-ID accuracy on unseen animals.
- Performance on PetFace, Flickr-Dog, or any other research dataset.

See `EVAL.md` at the repository root for how to obtain and run against those.
